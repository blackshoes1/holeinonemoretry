# 그래픽 고도화 개발 프롬프트 — 1차

```text
이 모바일 웹 골프 게임의 시각 레이어를 완성도 높은 카툰 골프장 방향으로 개선해줘.
이번 범위는 지형 색감·잔디 표현·조명 세 가지다. 아래 프롬프트 저장에 이어 구현을 진행한다.

작업 원칙:
- 저장소 지침과 미커밋 변경을 먼저 확인하고 기존 베타 기능·테스트를 보존한다.
- 물리 함수·상수·샷 매핑·코스 생성·점수·B 방식 스윙·사운드는 변경하지 않는다.
- 원본 타격음, 2.46초 시작점, 무가공 출력과 타격음 외 무음 상태를 유지한다.
- 새로운 나무 모델·HUD 개편·장비·광고·추가 게임 기능은 이번에 구현하지 않는다.
- 기존 Three.js와 HTML 구조를 유지한다. 외부 엔진이나 대형 라이브러리 추가 금지.
- 라이선스 확인이 필요한 외부 그래픽 자산을 임의로 가져오지 않는다.
- 기존 Vercel 프로젝트 연결을 유지한다. 커밋·push·배포는 별도 승인 없이 하지 않는다.

1. 지형 색감
- 러프·페어웨이·그린·모래를 명확히 구분하면서 과도한 형광색을 줄인다.
- 따뜻한 햇빛과 부드러운 배경색으로 일관된 팔레트를 만든다.
- 플레이 구역의 시각적 범위를 물리의 노면 범위에 맞춘다.
- 시각만 높이거나 장애물을 추가해 보이는 지형과 물리를 다르게 만들지 않는다.

2. 잔디 표현
- 페어웨이에 절제된 예초 무늬, 러프·그린에는 강도가 다른 미세한 질감을 적용한다.
- 저용량 절차적 텍스처 또는 동등한 경량 방식을 우선한다.
- 텍스처는 초기화 때 한 번 만들고 매 프레임 생성·갱신하지 않는다.
- 원거리 깜빡임을 줄이도록 밉맵과 필터링을 적용한다.
- 개별 잔디 메시 대량 생성이나 고비용 후처리는 넣지 않는다.

3. 조명
- 기존 광원의 색·강도를 조정해 밝은 면과 그늘을 정돈한다.
- 공·홀·조준 표시가 배경에서 잘 보여야 한다.
- 전 물체 실시간 그림자·SSAO·블룸 등 고비용 효과는 이번 범위에서 제외한다.
- 기존 카메라 near와 polygonOffset 등 z-fighting 방지 설정을 보존한다.

검증:
- 변경 전후 같은 코스·뷰포트·카메라 위치의 스크린샷을 확보한다.
- 같은 브라우저 조건에서 초기화 이후 프레임 간격을 측정하고 환경·표본 수를 명시한다.
- 가능하면 렌더 호출 수·삼각형 수·텍스처 수를 비교한다. 단순히 FPS가 60이라고 모바일 성능을 보장하지 않는다.
- 조준 화면·비행/착지 화면에서 질감과 공의 식별성을 확인한다.
- 물리·제스처·음원·베타 회귀 테스트를 실행한다.
- 실제 휴대폰 청음·GPU 성능·지면 반짝임을 확인하지 않았다면 미검증으로 표시한다.

완료 보고:
- 수정 파일과 시각적 변화
- 전후 스크린샷 위치
- 테스트와 성능 측정 결과, 측정 한계
- 유지한 동작과 미검증 항목
- 배포 여부
```
