# 그래픽 1차 구현·검증

## 변경 범위

- `game.js`: 카툰 팔레트와 기존 두 광원의 색·강도 조정. 러프·페어웨이·그린에 128×128 절차적 잔디 텍스처 각 1개 적용.
- 페어웨이 예초 무늬와 노면별 미세 질감. 텍스처는 초기화 시에만 생성하며 밉맵·선형 필터·최대 4배 이방성 필터를 사용한다.
- 텍스처 원본 데이터 합계 192 KiB, 전체 밉맵 포함 약 256 KiB. 이는 텍스처 데이터 계산값이며 실제 GPU 총 메모리 측정값은 아니다. 외부 다운로드 자산 없음.
- 페어웨이 표시 범위를 기존 물리 범위인 z=-20…350에 맞춤. 충돌·높이·물리 코어는 변경하지 않음.
- 실시간 그림자·후처리·풀잎 메시·새 광원 없음. 카메라 near=0.5와 polygonOffset 유지.
- `window.__golf.graphicsStats()` 읽기 전용 측정 함수, 실제 grassMap 대상 테스트와 로컬 브라우저 비교용 init script 추가.

## 전후 비교

로컬 headless Chromium, 400×800, DPR 1, 같은 코스·배경 난수·카메라 위치. 30프레임 예열 후 180개 requestAnimationFrame 간격 측정.

## 검증 결과

- 기존 회귀 테스트 19/19 통과, 추가 텍스처 테스트 1/1 통과.
- bench: Driver 269.2 yd(-0.3%), 7-Iron 171.8 yd(-0.1%), 기존 기준과 동일.
- aceSweep: 100m 4.4%, 130m 5.8%, 180m 3.0%, 기존 기준과 동일.
- 빠른 임팩트 98mph, 느린 임팩트 68mph; 원본 음원 바이트·2.46초 오프셋·무가공 출력 검증 통과.
- 텍스처 반복 생성 결과 동일, 불투명도·밉맵·필터·장치 이방성 상한 검증 통과.
- 실제 입력 경로로 조준→백스윙→릴리즈→비행→착지 결과 확인: 시작선 교차 때 발사/소리 없음, 릴리즈 때 실행, 결과 3점.
- 전후 조준 화면과 비행·착지 정지 화면을 직접 확인. 공·홀·조준 표시를 식별할 수 있었음.
- 브라우저 uncaught error 없음. JS 구문 및 git diff 공백 검사 통과.

## 보존·한계

물리, 샷 매핑, B 방식, 사운드, 점수, 코스 생성, 기존 베타 기능은 보존했다. 이번 그래픽 변경 후 9홀 전체 브라우저 플레이는 재실행하지 않았으며 관련 저장/복구 로직은 자동 회귀 테스트로 확인했다.

실제 휴대폰 GPU 성능·청음·움직이는 화면에서의 미세한 지면 반짝임은 미검증이다. 정지 화면만으로 깜빡임 제거를 단정하지 않는다. 커밋·push·배포하지 않았다.
